# WordUp - Vardu krajuma paplasinatajs

## Apraksts

WordUp ir aplikacija svesvalodu vardu apguvei. Lietotajs pievieno vardus ar tulkojumiem un macas tos ar kartisu (flashcard) metodi.
Paredzets skoleniem un ikvienam, kas velas uzlabot vardu krajumu.

---

## Uzstadisana

1. Lejupielade projektu:
   ```
   git clone https://github.com/sergejs_stefans/wordup
   ```

2. Atver projekta mapi:
   ```
   cd wordup
   ```

3. Instale bibliotekas:
   ```
   npm install
   ```

4. Palaid aplikaciju:
   ```
   npm start
   ```

---

## Lietosana

1. Atver aplikaciju
2. Pievieno jaunus vardus ar tulkojumiem
3. Atver "Macibu rezimu"
4. Atbildi uz kartisu jautajumiem
5. Skati savu progresu statistika

---

## Funkcijas

- Vardu pievienosana ar tulkojumu un piemera teikumu
- Kartisu (flashcard) macisanas rezims
- Tests ar variantiem (quiz)
- Progresa statistika (cik vardu apguts)
- Vardu grupesana pec temata (edieni, krasas, darbibas u.c.)

---

## Ka pievienot jaunu vardu

1. Nospied pogu "Pievienot vardu"
2. Ievadi vardu svesvaloda (piem.: "apple")
3. Ievadi tulkojumu (piem.: "abols")
4. Ievadi piemera teikumu (piem.: "I eat an apple every day")
5. Izveles tematu no saraksta vai izveido jaunu
6. Nospied "Saglabat"

Vards paradisies tava vardu saraksta un macibu kartites.
