# MemoryFun - Atminu spele berniem

## Apraksts

MemoryFun ir kartisu atminas spele berniem vecuma no 4 lidz 10 gadiem.
Speletajs atver kartites pa paariem un megina atrast vienadas bildes. Spele attista atminu un koncentresanos.

---

## Uzstadisana

1. Lejupielade projektu:
   ```
   git clone https://github.com/sergejs_stefans/memoryfun
   ```

2. Atver projekta mapi:
   ```
   cd memoryfun
   ```

3. Instale bibliotekas:
   ```
   npm install
   ```

4. Palaid speli:
   ```
   npm start
   ```

---

## Lietosana

1. Atver speli parlukprogramma
2. Izveles grutibu (viegls, videjs, gruts)
3. Spied uz kartitem, lai tas atvertu
4. Atrodi visus paarus

---

## Funkcijas

- Tris grutibu limeni (4, 8, 16 kartites)
- Krasu un dzivnieku temati
- Gajienu skaitakis
- Laika meritajs
- Rezultatu tabula (labakie laiki)
- Skanu efekti

---

## Ka sakt jaunu speli

1. Galvenaja lapa nospied "Jauna spele"
2. Izveles tematu (piem.: "Dzivnieki")
3. Izveles grutibu:
   - Viegls: 4 kartisu paari
   - Videjs: 8 kartisu paari
   - Gruts: 16 kartisu paari
4. Nospied "Sakt"
5. Spied uz kartitem pa divam, lai atrastu paarus
6. Kad visi paari atrasti, paradiisies rezultats

Merkis: pec iespejas mazak gajienu un isaks laiks.
