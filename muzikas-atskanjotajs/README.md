# SoundWave - Muzikas atskanjotajs

## Apraksts

SoundWave ir muzikas atskanjotajs, kas lauj klausities dziesmas, veidot atskannosanas sarakstus un atklat jaunu muziku.
Paredzets ikvienam, kas velas ertu un vienkaarsu muzikas pieredzi.

---

## Uzstadisana

1. Lejupielade projektu:
   ```
   git clone https://github.com/sergejs_stefans/soundwave
   ```

2. Atver projekta mapi:
   ```
   cd soundwave
   ```

3. Instale bibliotekas:
   ```
   npm install
   ```

4. Palaid aplikaciju:
   ```
   npm start
   ```

---

## Lietosana

1. Atver aplikaciju
2. Mekle dziesmu meklesanas lauka
3. Nospied uz dziesmas, lai saktu atskanjosanu
4. Izmanto vadibas pogas (play, pause, next)

---

## Funkcijas

- Dziesmu meklesana pec nosaukuma vai izpilditaja
- Atskannosanas sarakstu (playlist) veidosana
- Skanas regulesana
- Dziesmu kartiba: atkartot, jaukt
- Iecienito dziesmu saraksts

---

## Ka izveidot atskannosanas sarakstu

1. Nospied pogu "Jauns saraksts" kreisaja paneli
2. Ievadi saraksta nosaukumu (piem.: "Vakara dziesmas")
3. Nospied "Izveidot"
4. Mekle dziesmas meklesanas lauka
5. Nospied "+" blakus dziesmai, lai to pievienotu sarakstam
6. Atver sarakstu un nospied "Play", lai saktu atskanjosanu

Saraksts bus pieejams sadala "Mani saraksti".
