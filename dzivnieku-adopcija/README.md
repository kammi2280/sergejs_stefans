# PetHome - Dzivnieku adopcijas aplikacija

## Apraksts

PetHome ir aplikacija, kas savieno dzivnieku patversmes ar cilvekiem, kuri velas adoptet majdzivnieku.
Lietotajs var apskatit pieejamos dzivniekus, filtret tos pec veida un vecuma, ka ari pieteikties adopcijai.

---

## Uzstadisana

1. Lejupielade projektu:
   ```
   git clone https://github.com/sergejs_stefans/pethome
   ```

2. Atver projekta mapi:
   ```
   cd pethome
   ```

3. Instale bibliotekas:
   ```
   npm install
   ```

4. Palaid aplikaciju:
   ```
   npm start
   ```

---

## Lietosana

1. Atver aplikaciju parlukprogramma
2. Parskati pieejamo dzivnieku sarakstu
3. Izmanto filtrus, lai atrastu piemeerotu dzivnieku
4. Nospied "Uzzini vairak" uz izveleta dzivnieka
5. Aizpildi adopcijas pieteikumu

---

## Funkcijas

- Dzivnieku katalogs ar bildeem un aprakstiem
- Filtracija pec dzivnieka veida (suns, kakis, trusis u.c.)
- Filtracija pec vecuma un izmera
- Adopcijas pieteikuma forma
- Izlases saraksts (atzimeet iecienitakos dzivniekus)
- Patversmu kontaktinformacija

---

## Ka pieteikties dzivnieka adopcijai

1. Atver dzivnieku katalogu galvenaja lapa
2. Atrodi dzivnieku, kuru velies adoptet
3. Nospied pogu "Adoptet"
4. Aizpildi formu ar savu vardu, kontaktiem un dzivojamo platibu
5. Nospied "Nosutit pieteikumu"
6. Sanem apstiprinajumu uz e-pastu

Patversme sazinasies ar tevi 2-3 darba dienu laika.
