# TripPlan - Celojumu planotajs

## Apraksts

TripPlan ir aplikacija celojumu planosanai. Lietotajs var izveidot celojuma planu, pievienot galamerkus, aktivitates un izdevumus.
Paredzets ikvienam, kas velas organizet savu celojumu vienuviet.

---

## Uzstadisana

1. Lejupielade projektu:
   ```
   git clone https://github.com/sergejs_stefans/tripplan
   ```

2. Atver projekta mapi:
   ```
   cd tripplan
   ```

3. Instale bibliotekas:
   ```
   npm install
   ```

4. Palaid aplikaciju:
   ```
   npm start
   ```

---

## Lietosana

1. Atver aplikaciju
2. Izveido jaunu celojumu
3. Pievieno galamerkus un datumus
4. Pievieno aktivitates katrai dienai
5. Seko lidzi budzetam

---

## Funkcijas

- Celojuma plana izveidosana ar datumiem
- Galamerku pievienosana ar adresi
- Aktivitasu saraksts katrai dienai
- Budzeta izsekosana (planoti un faktiskie izdevumi)
- Celojuma kopsavilkuma skatijums

---

## Ka izveidot jaunu celojumu

1. Nospied pogu "Jauns celojums"
2. Ievadi celojuma nosaukumu (piem.: "Roma 2026")
3. Izveles sakuma un beigu datumu
4. Nospied "Izveidot"
5. Pievieno galamerku: nospied "+" un ievadi vietas nosaukumu
6. Katrai dienai pievieno aktivitates (piem.: "Apmeklet Kolizeju")
7. Pievieno planoto budzetu katrai aktivitatei

Celojuma plans bus pieejams sadala "Mani celojumi".
